SEE browser interoperability harness

Open this page on two devices or in two independent browser profiles. Exchange the generated QR images using any out-of-band channel. Each browser owns its own RTCPeerConnection; SEE only encodes and decodes the signaling messages.

ICE configuration

Empty configuration is useful on the same LAN. For different networks, configure STUN and, where needed, TURN credentials appropriate to your test environment. Do not put long-lived TURN credentials in a public test page.
